4Installation

In einer Minute installiert.

Installed in a minute.

  1. ZIP laden und entpacken.
  2. sh Install.sh ausführen. Fehlen GTK 4 oder polkit, kommen sie mit (pacman, apt, dnf, zypper). Auf Arch entsteht ein echtes pacman-Paket.
  3. Die App steht im Startmenü. Entfernen mit sh Uninstall.sh, deine Einstellungen bleiben.
  1. Download the ZIP and unpack it.
  2. Run sh Install.sh. GTK 4 or polkit come along if missing (pacman, apt, dnf, zypper). On Arch a real pacman package is built.
  3. The app is in your start menu. Remove it with sh Uninstall.sh, your settings stay.
oder alles in einem Befehlor all in one command
$ cd /tmp && curl -fLO https://github.com/Labtoso/Linux-AIO/releases/latest/download/Linux-AIO.zip && unzip -o Linux-AIO.zip && sh Linux-AIO/Install.sh

Andere App

Other app

Für SDDM Studio oder Hypr Studio im Befehl Linux-AIO durch SDDM-Studio oder Hypr-Studio ersetzen.

For SDDM Studio or Hypr Studio, replace Linux-AIO in the command with SDDM-Studio or Hypr-Studio.

Ohne Installation

Without installing

Die einzelne Programmdatei läuft auch so. Updates holt sie sich selbst über das Zahnrad, mit Prüfsumme.

The single binary runs as is. It fetches updates itself from the gear menu, checked by checksum.

5FragenQuestions
Welche Distributionen?
Arch und Arch-basierte (CachyOS, EndeavourOS, Manjaro) am besten, dazu Fedora, openSUSE, Debian 13 und Ubuntu 24.04 oder neuer. Gebraucht wird GTK 4.12 oder neuer.
Was ist neu in 3.0?
Alle drei Apps sind jetzt in Rust geschrieben, ohne Python und Qt, und starten schneller. Seiten, Einstellungen und Dateien sind gleich geblieben.
Bleiben meine Einstellungen?
Ja. Die neue Version liest dieselben Dateien unter ~/.config/LabtosoStudios.
Warum fragt die App nach dem Passwort?
Desktops, SDDM und Plymouth liegen im System. Dafür startet ein kleiner Helfer über polkit. Alles andere läuft als normaler Benutzer.
Kann ich es gefahrlos ausprobieren?
DEMANAGER_DRYRUN=1 linux-aio startet den Testmodus. Dann wird nichts am System geändert.
Kostet das etwas?
Nein. Linux AIO und SDDM Studio stehen unter GPL-3.0, Hypr Studio unter MIT. Der Quellcode liegt auf GitHub.
Which distributions?
Arch and Arch-based (CachyOS, EndeavourOS, Manjaro) work best, plus Fedora, openSUSE, Debian 13 and Ubuntu 24.04 or newer. GTK 4.12 or newer is needed.
What is new in 3.0?
All three apps are now written in Rust, without Python and Qt, and start faster. Pages, settings and files stayed the same.
Do my settings stay?
Yes. The new version reads the same files under ~/.config/LabtosoStudios.
Why does the app ask for a password?
Desktops, SDDM and Plymouth live in the system. A small helper starts through polkit for that. Everything else runs as your normal user.
Can I try it safely?
DEMANAGER_DRYRUN=1 linux-aio starts test mode. Nothing on the system is changed then.
Does it cost anything?
No. Linux AIO and SDDM Studio are GPL-3.0, Hypr Studio is MIT. The source code is on GitHub.
